# 调用者定义域与表示限制

强于模型所支持范围的定理，不是 C 正确性结果。本登记记录 API 适配器中的受限定义域和缺口。
每个比 `zlib.h` 更强的前置条件，也必须出现在对应定理的文档字符串中。
聚焦手册中的较窄例子，不改变固定公开目标，也不宣称被排除的调用具有未定义行为。
见[契约约定](api/contracts.md)。

完整目标仍然是：对公开 API 允许的全部调用，建立安全性、终止、frame、所有权和功能正确性。
本页不认证完成状态。[Overview](overview.md) 是唯一的剩余工作清单；
[信任基础](trusted-base.md)记录运行时选择。

## 构建与内存表示

| 领域 | 当前限制 | 影响 |
| --- | --- | --- |
| 初始配置 | 默认 x86_64 Linux、LP64、静态构建和默认分配器 | 其他上游配置和自定义分配器需要独立覆盖。默认分配失败仍在范围内。 |
| 选定的 inflate 组合里程碑 | 通过 `inflateInit_` 开始下游调用组合，使用 windowBits 15 和 zlib 封装 | 此首个组合里程碑不覆盖 raw/gzip/自动封装解码，也不覆盖通过 `inflateReset2` 切换参数的历史。独立的接受参数初始化定理覆盖它们被接受的初始参数。已有公开目标和一般历史定义保持不变。分配失败、畸形压缩输入和动态 Huffman 块仍在选定范围内。 |
| 接受参数的初始化定理 | `inflate_init2_valid_public` 明确假设 `Api.inflWbits` 接受给出的窗口参数 | 它在接受的定义域上证明未改变的公开初始化契约，包括内存失败和入口拒绝。它不证明完整的 `Goal.inflateInit2_`；该目标的无效窗口清理条款具有已检查的反例。 |
| 平台字节对象范围 | `Goal.inflate` 和内部快速路径 `PlatformEntry` 明确要求 `ByteObjectsFit`：每个活的表示字节数组都少于 `2^63` 个字节 | 这是有符号 `PTRDIFF_MAX` 对象界，不是 4 GiB 限制、总内存限制或流长度限制。现代 glibc 为成功的 malloc 家族分配提供这个界。对于其他调用者存储来源，这是明确的范围要求。它改变了原来无界的 inflate 定义域，需要语义审查。其他公开目标和不受限的运行时分配器不变。 |
| Adler 初始化查询 | `AdlerBufferBytes` 只在长度为零时允许 NULL；非空可读对象保留已有定义域 | 这项明确限制比固定头文件中未加条件的 NULL 表述更窄。它适用于 `Goal.adler32_z` 和 `Goal.adler32`；CRC 契约保持 `BufferBytes` 不变。 |
| 聚焦函数手册 | 条目可能要求有效句柄、分离缓冲区、真实字符串的校验值、生成的算子或给定调用顺序 | 这些是明确的文字范围。它们不缩减更广的 Lean 公开目标。 |
| 压缩器长度单元 | `Concrete.compress2_z` 和 `Concrete.compress2` 使用可选标量输入和返回的存储值 | 没有表示该单元与输入或输出的别名。若 C API 允许这种情况，完整指针定义域声明就需要解决它。空单元效果在 `_z` 和兼容包装器之间仍有差异。 |
| 带计数的解压单元 | 草案适配器保持输入长度、输出长度和数据区间互相分离 | 单元与数据之间或彼此之间的别名，不在这些适配器内。早期和晚期内存失败保留不同的标量效果。 |
| 压缩器数据关系 | `Compress2` 使用粗粒度拒绝标志描述数据 | `Compress2Z` 和 `Compress2Wrapper` 表达指针形状、错误顺序和长度存储。仅有数据模型定理不构成入口点精化。 |
| 上界算术 | LP64 上两种长度都是 64 位 | `Goal.compress_bound_value` 覆盖每个 `UInt64`，没有更小的数值前提。其他 ABI 需要大小转换陈述。单独的数值公式不等于输出足够性。 |
| CRC 地址与字访问 | `addrOf` 只观察地址低位。堆字节块保留起点对齐约定；静态和嵌入式字节对象具有任意且稳定的余数。字加载通过字节组装 | 一般 ABI 布局、任意原始块起点和 C 强制类型转换的别名语义，仍不在此抽象内。公开校验定义域不变。[静态地址回归](../tests/verification/regressions/crc-static-address.lean)将原模型反例的输入保留为正向检查。 |
| 空指针算术 | `Ptr.add` 允许空指针加零；`Ptr.diff` 对空指针产生故障，而压缩器辅助函数允许空指针减空指针 | 执行观测匹配不能建立 C 的有定义性。[分配回归](../tests/regression/compress-allocation/README.md)为零容量空目标保留了这一区别。 |

## Gz 外部世界

gz 世界是堆之外的受信任语义。它目前的范围小于 C 调用的系统接口。
[gz 翻译说明](translation-notes/gz-files.md)描述底层表示；公开 [gz 契约](api/gz-file.md)陈述操作定义域。

| 领域 | 当前限制 | 影响 |

## 局部打开、关闭与预置位里程碑

打开入口引理覆盖 NULL 参数、负描述符和初始分配失败。
它们不覆盖成功的解析器，也不建立完整公开打开契约。
读取器关闭执行里程碑假设已有 `GzGood` 不变量、读取模式和 `size = 0`。
该定义域排除了已初始化读取器，以及公开表示所允许的带非活动悬空缓冲区句柄。
它不从实际公开历史建立不变量。预置位入口引理覆盖被拒绝的流和 0 到 16 之外的位数；
被接受的位插入仍未完成。

这些是有范围限定的内部定理。它们都不替代或缩窄公开目标。
当前工作在 [overview](overview.md#public-api-proof-readiness) 中维护。
