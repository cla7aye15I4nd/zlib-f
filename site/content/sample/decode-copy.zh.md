[表安装完成](/sample/decode-tables.html) 后，解码器就能解释符号。它有两条执行路线：普通分派处理较小或被中断的工作；已有足够余量时，`inflate_fast` 省去许多重复的可用量检查。两者必须实现相同的字面量和匹配含义。

继续使用熟悉的匹配：在输出 `AB` 之后，长度六、距离二产生 `ABABAB`。这是选定的符号例子，不是完整 DEFLATE 流。先用它解释重叠，再转入跨尾的历史窗口和快速路径退出。

## 普通分派 {#dispatch}

慢速路径进入 `LEN`，查找字面量/长度表项，需要时跟随子表，再消费表项的编码位。字面量把模式改为 `LIT`；结束标记改为 `TYPE`；无效表项选择 `BAD`。长度基值则依次经过 `LENEXT`、在 `DIST` 中查距离、在 `DISTEXT` 中取距离额外位，最后进入 `MATCH`。

这些模式明确保存未完成工作。`LIT` 在写入前检查输出空间。`MATCH` 按剩余匹配长度、可用输出空间和源中连续部分的长度，限制每次复制。因此，缓冲区耗尽时可以把正的剩余长度留到下一次调用。其他状态处理存储块、动态表描述和封装字段。

翻译后的 [`inflate_LEN`](/reference/source/ZlibF/Zlib/inflate.c.html#L734) 也包含快速分支。默认配置不表示每次调用都走快路：缓冲区大小、已缓冲位数和当前模式会在运行时选择路线。

## 快速路径余量 {#margins}

主解码器在 `LEN` 中满足 `have ≥ 6`、`left ≥ 258`、`bits < 8` 时选择 `inflate_fast`。调用前把局部量恢复到流中，返回后再加载状态。辅助函数计算：

```text
last = in  + (avail_in  - 5)
end  = out + (avail_out - 257)
beg  = out - (start - avail_out)
```

`beg` 表示外层调用的输出起点，即使该调用在进入快速辅助函数前已经产生过字节。第一个循环体由 `do` 循环直接执行，所以入口余量必须已经成立。后续迭代使用 `in < last && out < end`。

一个匹配至多写出 258 字节。一个完整长度/距离 token 至多读取六个输入字节。若把各补充位置的最大值独立相加，会得到七，但这些最大值不可能同时出现：前面的补充留下足够的位，阻止最后一处也达到最大读取量。[快速解码参考](/reference/docs/proof/inffast.html#bit-counts-and-the-six-byte-bound) 展开这份账目。

## 顺序重叠 {#overlap}

若解码出的距离位于外层调用已经产生的输出内，源从 `out - dist` 开始。每个字节都在目标推进前读取。因此，后面的步骤可以读取同一匹配中前面步骤刚写入的字节。

距离为二时，前两次复制使用原来的 A 和 B；第三次读取第一次刚写出的 A。对初始源区间拍一个快照，不能表达这种行为。不相交的 `memcpy` 不足以替代重复规则，一般的快照式移动也不行。

## 保存的窗口与当前输出 {#window}

令 `done = out - beg`。若 `dist > done`，所缺的历史字节数为 `op = dist - done`。正常的 sane 距离检查拒绝 `op > whave`；仅有已分配窗口的容量，不能说明那些历史字节实际存在。

考虑一个大小八、已满且 `wnext = 3` 的教学环。物理单元保存 `ABCDEFGH`，所以按时间排序的历史是 `DEFGHABC`。当前调用已经产生 `DE`，现在要求长度六、距离六的匹配。于是 `done = 2`、`op = 4`，第一个窗口索引为：

```text
wsize + wnext - op = 8 + 3 - 4 = 7
```

先从单元 7 读取 `H`，回绕后再从单元 0 到 2 读取 `ABC`。四个窗口历史字节已经用完。匹配剩下的两个字节改从本次调用的输出读取，即 `DE`。匹配贡献 `HABCDE`，当前输出变为 `DEHABCDE`。

八个单元用来解释环形索引，不是允许的 `windowBits` 初始化大小。实际分支区分 `wnext = 0`、`0 < wnext < op` 和 `wnext ≥ op`。尚未填满的环还满足 `wnext = whave`；只能读取有效的保留历史。预设字典也可以提供历史，而不成为产生的输出。

## 展开的执行 {#unrolling}

快速辅助函数每轮复制多个字节，并处理最后一个或两个字节的余量。直接输出分支的 `do` 循环依赖最小匹配长度三。窗口前缀有各自的正计数器。源与目标重叠时，读写顺序尤其重要。

表链接同样通过向后的跳转回到 `dolen` 或 `dodist`。有效的已安装表把这种链接查找限制在一个子表级。无效长度或距离符号、不可用历史都经错误状态退出；块结束经规定模式退出。快路省去重复检查，不减少错误义务。

## 字节回退与写回 {#writeback}

返回前，辅助函数退回未使用的完整字节：

```text
whole = bits >> 3
in -= whole
bits -= whole << 3
hold &= (1U << bits) - 1
```

缓冲 19 位时，退回两个字节并保留三位。入口时已缓冲位数小于八，保证退回的是本辅助函数取入的字节，而不是进入之前取入的字节。最终收尾即使在错误退出时，也更新精确的游标、可用量、已缓冲位和模式。

这份算法阅读仍需执行论证 **to confirm**。小缓冲区必须由慢速分派覆盖，每个实际快速调用都必须建立快路前提。下一章把两条路线连接到 [同一个解码器论证](/sample/decode-proof.html)。完整的调用者影响和有定义的错误返回属于 [`inflate` 契约](/reference/functions/inflate.html)，不能从成功路径动画推出。
