# 早期源码变体

这些文本快照保留了与正式提供模块使用相同名称的早期定理陈述和证明。
它们不是编译的 Lean 模块，也不声称已经获得证明。
`status.json` 记录精确哈希和比较结果。

独有声明已另行暂存，定理陈述和证明正文保持原样。使用现有提供模块的
名称是一项明确标注的待检查集成方案。部分新旧契约不同，不能由旧编译
产物推断它们等价，或推断当前 Runtime 已接受这些源码。

这些记录描述归档时的检查点。当前接受结果和剩余工作以
[证明进度](../../../progress.md)为准。
