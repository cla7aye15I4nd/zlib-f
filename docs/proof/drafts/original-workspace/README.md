# Earlier source variants

These text snapshots preserve earlier statement and proof variants that share
names with canonical providers. They are not compiled Lean modules or claims
of proof. Their exact hashes and comparison status are in `status.json`.

Unique declarations are staged separately with their original statements and
proof bodies. Existing provider names are reused only as an explicit pending
integration proposal. Some old and current contracts differ. No equivalence
or current-runtime acceptance is inferred from an old compiled object.

These records are an archive checkpoint. See [current proof status](../../../progress.md)
for current accepted results and remaining work.
